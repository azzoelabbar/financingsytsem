# استراتيجية الترحيل (Output K)

الانتقال من `نموذج دليل الحسابات.xlsx` (168 حساباً) — والمُبذور في المرحلة 1 — إلى دليل الـ Enterprise (330 حساباً)، **بلا فقدان بيانات وبلا كسر الأرصدة**.

## المبادئ
1. **لا حذف، لا إعادة ترقيم.** كل رمز في الـBaseline يبقى بنفس `code`. التغييرات = إعادة تسمية + إثراء Metadata + ربط Contra + إضافة حسابات.
2. **قابل للعكس (Reversible):** Dry-run ثم Commit ثم إمكانية Rollback (بند 60).
3. **الأرصدة تُرحَّل عبر قيد افتتاحي متوازن** لا بتعديل مباشر.
4. **مسار تدقيق كامل** لكل تغيير (بند 31).

## جدول تحويل الحسابات (Account Crosswalk)
المصدر: `database/data/coa/coa_enterprise_libya.json` يحمل لكل حساب أصله (Baseline أو إضافة). التحويل:

| الحالة | الإجراء |
|---|---|
| حساب Baseline بلا تغيير | يُبقى كما هو، تُثرى الـMetadata فقط. |
| حساب Baseline أُعيدت تسميته (م.م.، إيجارات مستحقة) | `code` ثابت؛ يُحدَّث `name_ar/name_en`؛ يُسجَّل التغيير. |
| حساب Baseline أُعيد تصنيفه (Contra/OCI) | تُحدَّث الأعلام و`contra_of`؛ **الرصيد لا يتغيّر** (الطبيعة كانت صحيحة محاسبياً، تغيّر التمثيل فقط). |
| حساب جديد (162) | يُنشأ برصيد صفري؛ يُملأ بالقيود المستقبلية أو بقيد افتتاحي. |

## خطوات الترحيل (Wizard)
```
1. Backup            نسخة كاملة من الدليل والأرصدة الحالية.
2. Load Catalog      قراءة coa_enterprise_libya.json.
3. Map               مطابقة الرموز الحالية ↔ الكتالوج (تلقائي بالرمز + مراجعة استثناءات).
4. Validate (Dry-run) فحص: تفرّد الرموز، وجود الآباء، اتساق Contra/Normal Balance,
                      عدم يُتم حساب له رصيد، الأرصدة المرحّلة = الأصلية.
5. Preview           تقرير: كم حساب سيُنشأ/يُحدَّث/يُعاد تصنيفه + أي تحذيرات.
6. Commit            تطبيق ضمن معاملة واحدة (atomic).
7. Opening Balances  قيد افتتاحي متوازن ينقل الأرصدة إلى الحسابات (الجديدة/المعاد تصنيفها).
8. Reconcile         ميزان المراجعة بعد الترحيل = قبله (إجمالي المدين=الدائن، والمعادلة المحاسبية).
9. Lock / Audit      إقفال الترحيل وتسجيله في Audit Log.
Rollback: استعادة النسخة إن فشل أي فحص.
```

## قواعد إعادة تصنيف الأرصدة الحسّاسة
- **مجمعات الاستهلاك / مخصص الديون (Contra):** كانت بأرصدة دائنة صحيحة؛ يبقى الرصيد، يُضاف الربط `contra_of` فقط — لا قيد.
- **احتياطي إعادة التقييم → OCI:** إعادة تصنيف عرضي داخل حقوق الملكية؛ إن لزم، قيد إعادة تصنيف داخل الحقوق (لا أثر على صافي الحقوق).
- **VAT المجمّع → مدخلات/مخرجات/صافٍ:** يُبقى `210401` كحساب صافٍ؛ الحركات المستقبلية تُوجَّه للمدخلات/المخرجات؛ الرصيد الافتتاحي يبقى في الصافي أو يُفصَل بقيد تسوية عند توفر التفصيل.
- **الحسابات الختامية 7101/7102:** لا تُرحَّل بأرصدة (مؤقتة)؛ تُثبَّت system-only.

## التكامل مع المرحلة 1
- المرحلة 1 بذرت 168 حساباً عبر `ChartOfAccountsSeeder`. الترحيل لا يمسّ القيود المرحّلة.
