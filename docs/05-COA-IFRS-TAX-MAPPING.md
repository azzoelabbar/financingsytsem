# ربط المعايير الدولية والضرائب (Outputs D & E)

## D. IFRS / IAS Mapping

الربط يُخزَّن على مستوى الحساب (`ifrs_mapping` / `ias_mapping`) ويُجمَّع في **IFRS Mapping Layer** منفصلة (بند 5). النظام لا يدّعي الامتثال ما لم تُستوفَ المتطلبات.

| المعيار | الحسابات المرتبطة (أمثلة) |
|---|---|
| **IAS 2** المخزون | `1103x` المخزون، `620503` هبوط المخزون |
| **IAS 7** التدفقات النقدية | `cash_flow_classification` على كل حساب (operating/investing/financing) |
| **IAS 8** السياسات والأخطاء | `320203` تعديلات فترات سابقة |
| **IAS 12** ضريبة الدخل | `120401` أصل مؤجل، `220501` التزام مؤجل، `640101/102` مصروف جاري/مؤجل |
| **IAS 16** الممتلكات والمعدات | `1201xx` الأصول + مجمعات الاستهلاك، `120116` CWIP |
| **IAS 19** منافع الموظفين | `220401` التزام محدد، `220201` نهاية الخدمة، `330104` إعادة القياس (OCI) |
| **IAS 21** العملات الأجنبية | `420104/630104` محقق، `630105` غير محقق، `330102` احتياطي الترجمة |
| **IAS 23** تكاليف الاقتراض | رسملة ضمن `120116` CWIP (سياسة) |
| **IAS 24** إفصاحات الأطراف ذات العلاقة | حسابات `is_intercompany` (`110209/210108/1205/2206`) |
| **IAS 28 / IFRS 11** الزميلة والمشاريع المشتركة | `120302/120306` |
| **IAS 36** انخفاض القيمة | `120115/120206` مجمعات، `620501/502` خسائر |
| **IAS 37** المخصصات والمحتملات | `2106x` مخصصات، `810103` التزامات محتملة (Off-BS) |
| **IAS 38** الأصول غير الملموسة | `1202xx` + `120205` إطفاء، `120207` تطوير مرسمل |
| **IAS 40** الاستثمار العقاري | `120117/120118` |
| **IAS 41** الأصول البيولوجية | `120119` |
| **IFRS 9** الأدوات المالية | FVTPL `110603`، FVOCI `120304`، تكلفة مطفأة `120305`، مشتقات `110604/210901`، ECL `110204/630203`، تحوط `330103` |
| **IFRS 10** القوائم الموحّدة | `310104` NCI، حسابات الاستبعاد |
| **IFRS 15** الإيراد من العقود | أصل/التزام عقد `110207/210302`، اشتراكات `210303/410301`، على مدى الزمن `410401` |
| **IFRS 16** الإيجارات | حق الاستخدام `120112/113/114`، التزام `210503/220301`، استهلاك/فائدة `620407/630106` |
| **IFRS 7 / IAS 32** العرض والإفصاح للأدوات | تصنيفات FVTPL/FVOCI، أسهم خزينة `310103` |

**تصميم الطبقة:** لكل شركة إطار (`Full IFRS` / `IFRS for SMEs` / `Local GAAP`)؛ ولكل معيار: `Applicable? · Accounting Policy · Estimates · Effective Date · Transition · Disclosure`. الربط أعلاه يغذّي إفصاحات القوائم آلياً.

## E. Tax Mapping

الضرائب **ليست Hardcoded** (بند 22). `tax_mapping` على الحساب يربطه برمز ضريبي، والنِسَب/القواعد تعيش في Tax Engine كـ Configuration مع `Effective From/To · Legal Reference · Authority · Version`.

| رمز ضريبي | الحسابات | الملاحظة |
|---|---|---|
| `VAT` | Input `110210`، Output `210404`، مستحق `210405`، المجمّع `210401` | فصل المدخلات عن المخرجات + حساب صافٍ للتسوية |
| `CIT` | `210402` مستحقة، `640101` مصروف جاري | ضريبة دخل الشركات |
| `DEFERRED` | `120401/220501` أصل/التزام، `640102` مصروف | IAS 12 — فصل المعالجة المحاسبية عن الضريبية |
| `WHT` | `210403` | ضريبة الاستقطاع على المدفوعات |
| `PAYE` | `210702` | استقطاع ضريبة الدخل من الرواتب |
| `STAMP` | `210406` | ضريبة الدمغة |
| `SOLIDARITY` | `210407` | مساهمة التضامن الاجتماعي (ليبيا) — نسبة = Configuration |

**فصل جوهري (بند 22):** المعالجة المحاسبية (الدفتر LOCAL/IFRS) مفصولة عن المعالجة الضريبية (الدفتر TAX). نفس المعاملة تُنتج أرقاماً مختلفة في الدفتر الضريبي عبر Rules، والفروق الدائمة/المؤقتة تُنتج ضريبة مؤجلة.

**قابلية التدويل:** إضافة دولة = مجموعة رموز ضريبية جديدة + قواعدها، دون تعديل النواة (بند 62). ليبيا = القالب الأول؛ لا تُفترض أي نسبة — تُدخَل بمصدرها الرسمي (مصلحة الضرائب) في طبقة الامتثال.
