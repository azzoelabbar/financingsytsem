# أمثلة القيود العملية (Journal Examples)

18 نوع معاملة، كلٌّ بالسلسلة: **Source Transaction → Accounting Rule → Journal → Ledger → Financial-Statement Impact**. الأكواد من دليل الحسابات (`coa_enterprise_libya.json`). العملة LYD ما لم يُذكر غير ذلك.

> **تنبيه:** كل نِسَب الضرائب/الاشتراكات أدناه **توضيحية فقط** وتُحسب فعلياً في Tax Engine كـ Configuration بمرجعها القانوني (بند 22–23). لا نسبة مفترضة.
> **حسابات مقترحة للإضافة (النظام الدائم/المطابقة):** `510106 تكلفة البضاعة المباعة (COGS)` · `210109 بضاعة مستلمة لم تُفوتر (GRNI)`.

---

### 1) Sales — بيع آجل لبضاعة (نظام جرد دائم)
**Source:** فاتورة بيع (عميل، بضاعة 10,000، VAT توضيحي 200، تكلفة البضاعة 6,000). → **Rule:** `SalesInvoiceRule@IFRS15`.

| القيد (أ: الإيراد) | مدين | دائن |
|---|---|---|
| `110201` الذمم المدينة (AR) | 10,200 | |
| `410101` مبيعات محلية | | 10,000 |
| `210404` ضريبة القيمة المضافة على المخرجات | | 200 |

| القيد (ب: التكلفة) | مدين | دائن |
|---|---|---|
| `510106` تكلفة البضاعة المباعة | 6,000 | |
| `110301` المخزون | | 6,000 |

**Ledger:** AR (control + أستاذ العميل) ↑10,200 · Output VAT ↑200 · Inventory ↓6,000.
**FS Impact:** SFP: الأصول (AR↑، المخزون↓)، الخصوم (VAT↑). P&L: الإيراد +10,000، تكلفة المبيعات +6,000، مجمل الربح +4,000.

---

### 2) Purchase — شراء آجل (بضاعة/مصروف)
**Source:** فاتورة مورد (بضاعة 8,000 + VAT 160). → **Rule:** `PurchaseInvoiceRule`.

| القيد | مدين | دائن |
|---|---|---|
| `110301` المخزون (أو مصروف 62xx) | 8,000 | |
| `110210` ضريبة القيمة المضافة على المدخلات | 160 | |
| `210101` الموردون (AP) | | 8,160 |

**Ledger:** Inventory ↑8,000 · Input VAT ↑160 · AP (control + أستاذ المورد) ↑8,160.
**FS Impact:** SFP: الأصول (المخزون↑، ضريبة مدخلات مستردة↑)، الخصوم (AP↑). لا أثر على P&L حتى البيع.

---

### 3) Payment — سداد لمورّد
**Source:** أمر دفع للمورد 8,160. → **Rule:** `SupplierPaymentRule`.

| القيد | مدين | دائن |
|---|---|---|
| `210101` الموردون (AP) | 8,160 | |
| `110102` البنك الرئيسي | | 8,160 |

**Ledger:** AP ↓8,160 · Bank ↓8,160 (يحدّث الأستاذ المساعد للمورد).
**FS Impact:** SFP: الأصول (البنك↓)، الخصوم (AP↓). لا أثر على P&L. Cash Flow: تشغيلي −8,160.

---

### 4) Receipt — تحصيل من عميل
**Source:** إشعار تحصيل 10,200. → **Rule:** `CustomerReceiptRule`.

| القيد | مدين | دائن |
|---|---|---|
| `110102` البنك الرئيسي | 10,200 | |
| `110201` الذمم المدينة (AR) | | 10,200 |

**Ledger:** Bank ↑ · AR ↓ (أستاذ العميل).
**FS Impact:** SFP: تبادل داخل الأصول (بنك↑، AR↓)، لا أثر على الحقوق. Cash Flow: تشغيلي +10,200.

---

### 5) Inventory — استلام مخزون (GRNI) ثم فوترة
**Source:** إذن استلام بضاعة (قبل الفاتورة) 8,000. → **Rule:** `InventoryReceiptRule`.

| عند الاستلام | مدين | دائن |
|---|---|---|
| `110301` المخزون | 8,000 | |
| `210109` بضاعة مستلمة لم تُفوتر (GRNI) | | 8,000 |

| عند وصول الفاتورة | مدين | دائن |
|---|---|---|
| `210109` GRNI | 8,000 | |
| `110210` ضريبة مدخلات | 160 | |
| `210101` الموردون | | 8,160 |

**Ledger:** Inventory ↑ فور الاستلام؛ GRNI يُقفل عند الفوترة.
**FS Impact:** SFP: يعكس الالتزام الفعلي حتى لو تأخرت الفاتورة (مبدأ الاستحقاق).

---

### 6) Fixed Asset — اقتناء أصل ثابت
**Source:** فاتورة شراء آلة 50,000 + VAT 1,000. → **Rule:** `FixedAssetAcquisitionRule` (IAS 16) + إنشاء بطاقة أصل في الأستاذ المساعد FA.

| القيد | مدين | دائن |
|---|---|---|
| `120104` الآلات والمعدات | 50,000 | |
| `110210` ضريبة مدخلات | 1,000 | |
| `210101` الموردون | | 51,000 |

**Ledger:** PPE ↑ (control + سجل الأصل، مع تاريخ الرسملة والعمر الإنتاجي).
**FS Impact:** SFP: أصول غير متداولة ↑. لا أثر على P&L (يُرسمل لا يُصرف).

---

### 7) Depreciation — إهلاك دوري (آلي)
**Source:** تشغيل الإهلاك الشهري (قسط ثابت، الآلة 50,000 / 5 سنوات = 833.33/شهر). → **Rule:** `DepreciationRule` (recurring).

| القيد | مدين | دائن |
|---|---|---|
| `620402` استهلاك الآلات والمعدات | 833.33 | |
| `120105` مجمع استهلاك الآلات والمعدات (Contra) | | 833.33 |

**Ledger:** مصروف الإهلاك ↑ · مجمع الاستهلاك (Contra-Asset) ↑ → صافي القيمة الدفترية ↓.
**FS Impact:** P&L: مصروف +833.33. SFP: صافي الأصول الثابتة ↓833.33. Cash Flow: بند غير نقدي يُضاف في التشغيلي.

---

### 8) Payroll — مسير رواتب (آلي)
**Source:** مسير شهري (إجمالي 10,000؛ PAYE توضيحي 500؛ ضمان اجتماعي موظف 375؛ حصة صاحب العمل 750). → **Rule:** `PayrollRule`.

| القيد | مدين | دائن |
|---|---|---|
| `620101` رواتب الموظفين الإداريين | 10,000 | |
| `620102` بدلات ومزايا (حصة صاحب العمل للضمان) | 750 | |
| `210702` استقطاع ضريبة الدخل (PAYE) | | 500 |
| `210703` ضمان اجتماعي — حصة الموظف | | 375 |
| `210704` ضمان اجتماعي — حصة صاحب العمل | | 750 |
| `210701` صافي الرواتب المستحقة | | 9,125 |

**Ledger:** مصروف الرواتب 10,750 · التزامات (ضريبة/ضمان/صافٍ) 10,750. عند الدفع: `210701` مدين / `110102` دائن.
**FS Impact:** P&L: مصروفات +10,750. SFP: خصوم متداولة ↑ حتى السداد.

---

### 9) Tax — تسوية ضريبة القيمة المضافة (نهاية الفترة)
**Source:** إقفال فترة VAT (مخرجات 1,500، مدخلات 900). → **Rule:** `TaxSettlementRule`.

| القيد | مدين | دائن |
|---|---|---|
| `210404` ضريبة مخرجات | 1,500 | |
| `110210` ضريبة مدخلات | | 900 |
| `210405` ضريبة القيمة المضافة مستحقة الدفع | | 600 |

**Ledger:** يُصفّى حسابا المدخلات/المخرجات، ويظهر الصافي المستحق. عند السداد: `210405` مدين / `110102` دائن.
**FS Impact:** SFP: خصوم (VAT مستحق 600). Cash Flow: تشغيلي عند السداد.

---

### 10) Loan — الحصول على قرض وسداد قسط
**Source:** سحب قرض 100,000 ثم قسط شهري (فائدة 500 + أصل 2,000). → **Rules:** `LoanDrawdownRule` / `LoanRepaymentRule`.

| سحب القرض | مدين | دائن |
|---|---|---|
| `110102` البنك | 100,000 | |
| `220101` قروض بنكية طويلة الأجل | | 100,000 |

| سداد القسط | مدين | دائن |
|---|---|---|
| `630101` فوائد قروض بنكية | 500 | |
| `220101` قروض طويلة الأجل (أصل) | 2,000 | |
| `110102` البنك | | 2,500 |

**Ledger:** التزام القرض ↓ بالأصل فقط؛ الفائدة مصروف. (إعادة تصنيف الجزء المتداول: `220101` مدين / `210502` دائن).
**FS Impact:** سحب — SFP: بنك↑، قرض↑ (Cash Flow: تمويلي +100,000). سداد — P&L: فائدة 500؛ Cash Flow: تمويلي (أصل) + تشغيلي/تمويلي (فائدة).

### 11) Lease — إيجار وفق IFRS 16 (دفتر IFRS)
**Source:** عقد إيجار 3 سنوات، القيمة الحالية للدفعات 30,000؛ دفعة سنوية 11,000 (فائدة 2,000). → **Rules:** `LeaseInitialRule@IFRS` ثم `LeasePaymentRule@IFRS` + `DepreciationRule`.

| الإثبات الأولي | مدين | دائن |
|---|---|---|
| `120112` حق استخدام أصل — عقارات | 30,000 | |
| `220301` التزام إيجار طويل الأجل | | 30,000 |

| دفعة الإيجار | مدين | دائن |
|---|---|---|
| `630106` فائدة التزام الإيجار | 2,000 | |
| `210503` الجزء المتداول من التزام الإيجار | 9,000 | |
| `110102` البنك | | 11,000 |

| إهلاك حق الاستخدام (30,000/3) | مدين | دائن |
|---|---|---|
| `620407` استهلاك حق استخدام الأصل | 10,000 | |
| `120114` مجمع استهلاك حق الاستخدام (Contra) | | 10,000 |

**Multi-Book:** في دفتر `TAX`/`LOCAL` قد تُعامل كإيجار تشغيلي: `620201` مصروف إيجار / `110102` بنك — نفس المستند، قاعدة مختلفة.
**FS Impact (IFRS):** SFP: أصل حق استخدام + التزام إيجار. P&L: استهلاك + فائدة (بدل مصروف إيجار واحد).

### 12) FX Revaluation — إعادة تقييم بند نقدي بالعملة الأجنبية
**Source:** إعادة تقييم آخر الفترة. التزام مورد USD 1,000 أُثبت بسعر 4.80 (=4,800)؛ سعر الإقفال 4.90 (=4,900). → **Rule:** `FxRevaluationRule` (IAS 21).

| القيد (خسارة غير محققة) | مدين | دائن |
|---|---|---|
| `630105` خسائر فروق العملة غير المحققة | 100 | |
| `210101` الموردون (USD) | | 100 |

**Ledger:** رصيد المورد بالوظيفية يُحدَّث لسعر الإقفال؛ الفرق غير المحقق في P&L. (عند السداد الفعلي يتحوّل إلى محقق `630104`/`420104`).
**FS Impact:** SFP: الالتزام بالأجنبي بالقيمة العادلة. P&L: خسارة فروق عملة 100.

### 13) Bad Debt / Write-off — إعدام دين
**Source:** اعتماد إعدام ذمة عميل 3,000 (مغطاة بالمخصص). → **Rule:** `BadDebtWriteOffRule`.

| القيد | مدين | دائن |
|---|---|---|
| `110204` مخصص خسائر ائتمانية متوقعة (Contra) | 3,000 | |
| `110201` الذمم المدينة | | 3,000 |

**Ledger:** يُستنفد المخصص مقابل شطب AR (لا أثر على P&L لأن الخسارة أُثبتت سابقاً عبر ECL).
**FS Impact:** SFP: AR الإجمالي↓ والمخصص↓ (صافي AR ثابت). لا أثر على P&L.

---

### 14) ECL — خسائر ائتمانية متوقعة (IFRS 9)
**Source:** حساب المخصص آخر الفترة (زيادة مطلوبة 1,200). → **Rule:** `EclRule` (نموذج IFRS 9).

| القيد | مدين | دائن |
|---|---|---|
| `630203` مصروف الخسائر الائتمانية المتوقعة | 1,200 | |
| `110204` مخصص خسائر ائتمانية متوقعة (Contra) | | 1,200 |

**Ledger:** المخصص (Contra-Asset) ↑ → صافي AR ↓.
**FS Impact:** P&L: مصروف ECL +1,200. SFP: صافي الذمم المدينة ↓1,200.

### 15) Revenue Recognition — إيراد على مدى الزمن (IFRS 15، SaaS)
**Source:** اشتراك سنوي 1,200 مقبوض مقدماً، يُعترف شهرياً. → **Rule:** `RevenueRecognitionRule@IFRS15`.

| عند القبض | مدين | دائن |
|---|---|---|
| `110102` البنك | 1,200 | |
| `210303` إيراد اشتراكات مؤجل (التزام عقد) | | 1,200 |

| الاعتراف الشهري (recurring) | مدين | دائن |
|---|---|---|
| `210303` إيراد اشتراكات مؤجل | 100 | |
| `410301` إيرادات اشتراكات | | 100 |

**Ledger:** الالتزام (إيراد مؤجل) يتناقص 100/شهر مقابل إيراد معترف.
**FS Impact:** عند القبض — SFP: بنك↑، التزام عقد↑ (لا إيراد). شهرياً — P&L: إيراد +100، الالتزام↓100.

### 16) Intercompany — معاملة بين شركات المجموعة
**Source:** الشركة الأم تقدّم خدمة للتابعة 5,000. → **Rule:** `IntercompanyRule` (طرفان في كيانين).

| في الأم | مدين | دائن |
|---|---|---|
| `110209` ذمم مدينة بين الشركات | 5,000 | |
| `410201` إيرادات خدمات رئيسية | | 5,000 |

| في التابعة | مدين | دائن |
|---|---|---|
| `620303` رسوم/خدمات | 5,000 | |
| `210108` ذمم دائنة بين الشركات | | 5,000 |

| قيد الاستبعاد (عند التوحيد فقط، دفتر Consolidation) | مدين | دائن |
|---|---|---|
| `410201` إيراد (أم) | 5,000 | |
| `620303` مصروف (تابعة) | | 5,000 |
| `210108` IC دائنة | 5,000 | |
| `110209` IC مدينة | | 5,000 |

**Ledger:** الأرصدة `is_intercompany` موسومة `eliminate_on_consolidation`؛ تُطابَق وتُستبعد.
**FS Impact:** على مستوى كل كيان: عادي. على المستوى الموحّد: **صفر** (الإيراد والمصروف والذمم المتقابلة تُلغى).

### 17) Year-End Closing — إقفال آخر السنة (آلي، دفتر واحد)
**Source:** تشغيل الإقفال السنوي. → **Rule:** `YearEndClosingRule` (system-only، على حسابات ختامية).

| إقفال الإيرادات | مدين | دائن |
|---|---|---|
| `4xxxxx` كل حسابات الإيراد | إجمالي | |
| `710101` ملخص الأرباح والخسائر | | إجمالي |

| إقفال المصروفات والتكلفة | مدين | دائن |
|---|---|---|
| `710101` ملخص الأرباح والخسائر | إجمالي | |
| `5xxxxx / 6xxxxx` كل المصروفات | | إجمالي |

| ترحيل الصافي للأرباح المرحّلة | مدين | دائن |
|---|---|---|
| `710101` ملخص الأرباح والخسائر (صافي ربح) | الصافي | |
| `320201` أرباح مرحّلة | | الصافي |

**Ledger:** الحسابات المؤقتة (إيراد/مصروف) تصبح صفراً؛ الصافي ينتقل للحقوق. الحسابات الدائمة (أصول/خصوم/حقوق) تُرحَّل أرصدتها للسنة الجديدة.
**FS Impact:** P&L يصفّر للسنة الجديدة؛ الأرباح المرحّلة في SFP ↑ بصافي الربح؛ المعادلة المحاسبية محفوظة.

### 18) Accrual & Prepayment — استحقاق ودفعة مقدمة
**Source (استحقاق):** مصروف كهرباء 400 استُهلك ولم تصل فاتورته آخر الفترة. → **Rule:** `AccrualRule` (عكس تلقائي أول الفترة التالية).

| إثبات الاستحقاق | مدين | دائن |
|---|---|---|
| `620202` كهرباء وماء | 400 | |
| `210203` مصروفات مستحقة أخرى | | 400 |
*(يُعكس آلياً أول الشهر التالي عند ورود الفاتورة الفعلية.)*

**Source (دفعة مقدمة):** إيجار سنوي 12,000 مدفوع مقدماً، يُطفأ 1,000/شهر. → **Rule:** `PrepaymentRule`.

| الدفع | مدين | دائن |
|---|---|---|
| `110401` إيجار مدفوع مقدماً | 12,000 | |
| `110102` البنك | | 12,000 |

| الإطفاء الشهري (recurring) | مدين | دائن |
|---|---|---|
| `620201` إيجار المكاتب | 1,000 | |
| `110401` إيجار مدفوع مقدماً | | 1,000 |

**FS Impact:** الاستحقاق — P&L مصروف +400، SFP خصم +400. الدفعة المقدمة — SFP أصل↑ ثم يتناقص مع اعتراف المصروف شهرياً (مبدأ المقابلة).

## ملخّص التتبّع (Traceability)
كل قيد أعلاه يحمل: `source` (نوع المستند) · `source_ref` (رقم الفاتورة/المسير) · `ruleVersion` · `book_id` · الأبعاد. لذا أي رقم في القائمة المالية قابل للتنقل:
**Statement → Account → Ledger → Journal → Source Transaction → Original Document** (بند 11، 68).
